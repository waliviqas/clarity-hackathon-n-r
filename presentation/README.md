# Clarity presentation site

A single-file, scroll-driven presentation of Clarity: open `index.html` in a browser (no build, no server). It needs an internet connection only for Google Fonts.

**Controls:** arrow keys, space, a scroll-wheel flick or a swipe each advance one step; Home and End jump to the start and end. A counter in the bottom-right shows the step.

**Acts:** title, problem and the camera-graph search come from Wali's earlier [police-surveillance-demo](https://github.com/waliviqas/police-surveillance-demo) site. Acts 04–11 and the closing card were added for this hackathon: pipeline, the three models, fine-tune results, open data, the live run on test clip 1, the coordinator, vLLM serving, limits, team and links.

Every number on the page comes from this repo's README, `runs/run_live2_1027/RUN.md` and `VLLM_BOUNTY.md`. Change those first, then the page.
