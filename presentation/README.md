# Clarity presentation site

A single-file, scroll-driven presentation of Clarity: open `index.html` in a browser (no build, no server). It needs an internet connection only for Google Fonts.

**Controls:** arrow keys, space, a scroll-wheel flick or a swipe each advance one step; Home and End jump to the start and end. A counter in the bottom-right shows the step.

**Acts:** title, problem and the camera-graph search come from Wali's earlier [police-surveillance-demo](https://github.com/waliviqas/police-surveillance-demo) site. Two acts and a closing card were added for this hackathon: how it works (five steps, three models on vLLM), the fine-tune result, and team and links. It is kept short on purpose: the demo video is 3–5 minutes and shows the live run on the dashboard itself.

Every number on the page comes from this repo's README, `hf_model/README.md`. Change those first, then the page.
