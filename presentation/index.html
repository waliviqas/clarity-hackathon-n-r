09 · The coordinator
The model writes. Code checks. A human decides.
Themodelwrites.
Codechecks.
Ahumandecides.
01 · RULES FIRST

No wait on a stabbing

Clear cases alert at once with no model call. Code computes the path and where the suspect is heading.

02 · NEMOTRON 9B

Writes the call

For the rest, the model writes the recommendation as JSON, told where to send officers and the priority cap.

03 · VERIFIER

Code checks it

Made-up evidence, unknown cameras, the wrong destination or an inflated priority are rejected. One retry, then operator review.

Every alert waits for the operator's Confirm or Dismiss · in our tests officers were never sent to a decoy exit
