# runs/: recorded runs
The bus writes every accepted event to `runs/<run_id>/events.jsonl` (and when it accepted each to `arrivals.jsonl`); `python -m bus.replay runs/<run_id>/events.jsonl` plays a run back into the dashboard, `python -m bus.metrics runs/<run_id>` measures it.
`run_lookout_scripted/` is a scripted "cold trail" story: clip 1's chase, then the same suspect picked up 38 minutes later (the true filming gap) at `cam_14`, placed on Hillsborough St for this story (about 2.4 km away; its footage is clip 8's cam2, filmed about 200 m from clip 1). Scripted perception, real footage, coordinator in rules mode; replay with `python -m bus.replay runs/run_lookout_scripted/events.jsonl --speed 1 --max-gap 5` on a bus started with `CLARITY_CAMERAS=data/sites/annex_lookout/cameras.json` (see its `RUN.md`).
`run_1018-0028_r2s/` is the earlier scripted clip-8 fallback: scripted perception, dispatcher in rules mode, no model ran, so its timings are not model latency (see its `RUN.md`).
